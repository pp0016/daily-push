## 🎯 Content Structure That Gets 60%+ Retention

All these niches use the same formula:

```
Hook (0-5 sec) → "What you're about to see will shock you..."
Tension Build (5-60 sec) → Context, backstory, slow reveal
Payoff (60-90 sec) → The actual scary/shocking moment
Reset → "But that's nothing compared to the next one..."
Repeat → Next clip/story (for compilations)
```

**Pro tips:**
- Drop a micro-hook every 60-90 seconds ("But wait, it gets worse...")
- Remove ALL dead air / silence longer than 0.5 seconds
- Use subtle zoom/pan on images to keep visuals "alive"
- At the 50% mark, tease: "The craziest one is still coming..."
